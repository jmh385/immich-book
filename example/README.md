# Example book (no Immich server, no network)

`immich-book-example.pdf` and `example-summary.json` are generated by the Jest
test in `src/utils/__tests__/exampleBook.test.ts` from 14 mock photos. The PDF
draws a colored placeholder rectangle where the app would draw the Immich
thumbnail, so you can check grouping, page styles and captions without a
server.

Regenerate:

```bash
npm test -- exampleBook
```

What to look at in the PDF:

- **Grouping** — Funchal (14, 15 and 22 July), Lisbon (23 July) and Porto
  (24 July) each start on a new page; the hierarchy is location runs, then days
  within them.
- **Automatic layout styles** — the 3-photo days use "mixed" (one large photo
  plus rows), the single 22 July photo fills a "spotlight" page, the 4-photo
  Porto day uses justified rows.
- **Automatic captions** — the first page of each group carries a caption such
  as "Funchal, 14 July 2026, with Alice & Bob", generated from location, date
  and people. Later pages of a group carry none.

`example-summary.json` contains the same information as data (groups, chosen
styles, captions, page breakdown) for checking without opening the PDF.
